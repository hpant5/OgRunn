# Figma Implementation Notes

Use Figma for visual layout and styling only.

Figma may define:

- Main menu layout
- HUD layout
- Pause/game-over/level-complete screens
- Button styles
- Colors, fonts, icons, and placeholder art direction

Figma must not define:

- Maze collision
- Ogre AI
- Pathfinding
- Game states
- Level progression
- Player movement rules

If Figma conflicts with `Ogrerunn V1 Readme.pdf`, use the PDF for gameplay behavior.
